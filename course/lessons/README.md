# Becoming Doom: the 18 full lessons (version 2)

Written 31 October 2026. These are the full teaching scripts for all 18 video lessons, three per week. Each one replaces the shorter first draft, which is kept in the same lesson folder.

## Where everything lives

- **Master copy of each lesson:** `course/Wxx-Lyy/Wxx-Lyy-script-v2.md` in the project files (here in the repo: `course/lessons/Wxx-Lyy.md`), next to the old `Wxx-Lyy-script.md` and that lesson's slides.
- **Reading copies by week:** `course/full-lessons-v2/Week-1-Claim-the-Throne.md` and so on, all three lessons of a week in one file.
- **Whole course in one file:** `course/full-lessons-v2/Becoming-Doom-all-18-lessons-v2.md`.
- If you edit a lesson, edit the master copy; the reading copies are generated from it.

## How every lesson is built

Each lesson keeps the slide format the deck builder uses (one block per slide: kind, On screen, Visual, Say). Inside that, every lesson now has the same teaching spine:

1. Hook and question, tied back to the previous lesson
2. The principle and, from week two, the new thinking tool with its limit
3. The lead case with three compared responses
4. A second real case from a different kind of life
5. Where people go wrong (four mistakes, including the misreading of the principle)
6. A three-line recap
7. Guided practice with a pause, the workbook mission and a closing line

Even-numbered slides are real-life scene images with the words set over them, following Edem's slide rule, and each carries an image brief. The hooded figure darkens week by week and the course ends on the faceless figure.
