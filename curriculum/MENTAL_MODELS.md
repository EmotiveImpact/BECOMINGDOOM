# Reasoning toolkit

Ten tools, two per week from week two. M02 is a practical sorting heuristic; this is a mixed toolkit, not ten universally validated scientific laws. Original teaching prompts follow. Research index R07 is a conceptual reference, not an effectiveness trial.

## M01: Opportunity cost

Introduce: week 2.

Question: What is the best realistic alternative I give up?

Limit: Avoid valuing every free hour as if it could earn unlimited money.

Practice: use the tool on the current Doom Project, identify an assumption and state the resulting action. Revisit in each later week; choose tools based on relevance rather than using all ten.
