# Week 5: Build the Empire

**Question:** Can I turn capability into useful value?

New creed emphasis: P05, P10. New models: M07, M08. Source cards: R07, R09.

## The change to look for

From private building to a clear offer tested with the intended audience.

## Three core lesson briefs

### W05-L01: Find useful leverage

Teach: Introduce leverage as useful output per constrained resource. Identify the audience’s actual problem.

Worked example: A clear onboarding checklist can prevent repeated confusion; automating unclear instructions just repeats confusion faster.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W05-L02: Close the loop

Teach: Introduce feedback loops with a useful measure, review interval and adjustment rule.

Worked example: Track whether a user completes the task rather than whether they praise the idea.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W05-L03: Make the offer

Teach: Define result, scope, time, costs and requested commitment. Use previous negotiation and boundary work.

Worked example: A limited pilot with a scheduled review creates better evidence than an open-ended promise to help everyone.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

## Seven-day delivery map

### Day 29: Locate the value

Time: 50 minutes. Workbook ID: W05-D01.

Mission: Use M07 to choose the work that most improves the audience’s result.

Evidence: Audience/problem statement and one leverage hypothesis.

Carry forward: relate today’s choice to the personal doctrine and a boundary or considered commitment. Log priority, pressure, response, evidence and correction.

## Workbook and slide production

Use one daily page per workbook ID, plus a weekly evidence review. Each page needs the mission, response fields, an original worked example and the evidence criterion. Slide production should follow the three lesson briefs; do not turn every workbook instruction into a slide.

## Weekly review

Use the common assessment rubric. Identify missing evidence and a feasible revision; no pass depends on a positive response from another person. Before the next week, give one specific observation, one correction and one next action.
