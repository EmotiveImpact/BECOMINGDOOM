# Week 3: Enter the Laboratory

**Question:** What can I actually do?

New creed emphasis: P07. New models: M03, M04. Source cards: R04, R07, R09.

## The change to look for

From consuming ideas to demonstrating a useful capability and revising from feedback.

## Three core lesson briefs

### W03-L01: Think from zero

Teach: Introduce first principles: distinguish requirements, observations and assumptions. Reuse opportunity cost to keep scope feasible.

Worked example: A useful portfolio does not require a custom platform; it requires evidence a prospective client can assess.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W03-L02: Invert the failure

Teach: Introduce inversion and create a small prevention plan. Choose one subskill to practise with feedback.

Worked example: A demo will fail if nobody can open it; test access before adding another feature.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W03-L03: Build your first Doombot

Teach: Create a bounded repeatable aid: template, checklist or optional automation. Check outputs against an explicit rubric.

Worked example: A draft-report helper may reduce repetition, but a human checks accuracy and avoids entering private client information.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

## Workbook and slide production

Use one daily page per workbook ID, plus a weekly evidence review. Each page needs the mission, response fields, an original worked example and the evidence criterion. Slide production should follow the three lesson briefs; do not turn every workbook instruction into a slide.

## Weekly review

Use the common assessment rubric. Identify missing evidence and a feasible revision; no pass depends on a positive response from another person. Before the next week, give one specific observation, one correction and one next action.
