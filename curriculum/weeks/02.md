# Week 2: Build the Fortress

**Question:** Can I trust myself to execute?

New creed emphasis: P09, P12, P13. New models: M01, M02. Source cards: R04, R05, R06.

## The change to look for

From intention to a realistic system that produces work and survives disruption.

## Three core lesson briefs

### W02-L01: Every yes spends your life

Teach: Introduce opportunity cost. Compare options against the best realistic alternative rather than a fantasy of doing everything.

Worked example: A two-hour favour displaces either project work or rest; name which cost you are willing to bear.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W02-L02: Build conditions for execution

Teach: Introduce control and influence as a practical sorting tool. Create a command sheet and an if–then response to a likely interruption.

Worked example: You cannot guarantee an uninterrupted evening, but you can silence notifications and prepare a shorter fallback session.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

### W02-L03: Body, standards and recovery

Teach: Choose appropriate movement and recovery routines. Set a realistic commitment and a reset procedure.

Worked example: A missed session leads to a revised next step rather than a punitive all-night catch-up.

Production: 8–10 minute lesson; one proposition, one mistaken response, one improved response, one guided rehearsal. Use the matching daily mission below for application. Avoid adding a second assignment.

## Workbook and slide production

Use one daily page per workbook ID, plus a weekly evidence review. Each page needs the mission, response fields, an original worked example and the evidence criterion. Slide production should follow the three lesson briefs; do not turn every workbook instruction into a slide.

## Weekly review

Use the common assessment rubric. Identify missing evidence and a feasible revision; no pass depends on a positive response from another person. Before the next week, give one specific observation, one correction and one next action.
