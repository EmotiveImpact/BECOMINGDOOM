# Original visual direction

The ten-image state sequence is the creator's existing Becoming Doom artwork, not a new substitute aesthetic. `IMAGE_INVENTORY.json` records its order, titles, byte sizes and SHA-256 checksums.

The visual language combines monumental basalt architecture, restrained ivory and gold accents, atmospheric scale and a human figure whose decisions remain central. Images serve the lesson's decision or transition; the artwork is not itself proof of a course outcome.

Image binaries and finished presentation/PDF files are delivered separately to the creator. They are **not included in this repository commit**. The inventory is an integrity and production reference, not a public download mechanism or a grant of reuse rights. No private delivery identifiers or signed download URLs are published.

The existing curriculum is six taught weeks and forty-two daily missions. A separate visual's sixty-one-day wording remains unresolved; do not infer approval to replace the schedule from artwork alone.
